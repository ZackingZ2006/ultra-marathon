# Ultra-marathon tại Mỹ năm 2020

Phân tích mô tả tốc độ và lượt tham dự ở cự ly 50 km và 50 mile bằng Python. [Xem notebook](Ultra_marathon_hoan_chinh.ipynb).

Phạm vi gồm 26.524 lượt; phân tích theo tuổi, giới tính và mùa, kèm kiểm tra chất lượng và ảnh hưởng của trọng số. Các so sánh mang tính mô tả.

Tải `ultra-marathon.zip`, giải nén rồi xem README trong thư mục để chạy notebook và script. Dữ liệu nguồn: [The Big Dataset of Ultra Marathon Running](https://www.kaggle.com/datasets/aiaiaidavid/the-big-dataset-of-ultra-marathon-running). Bài ban đầu làm theo tutorial; chưa tìm lại được đường dẫn gốc.
